# Agent 05 — Performance learning

At the end of each week, compare posts by format, pillar, topic and CTA.

Report:
- what appears to have worked, with numbers and sample size
- what remains inconclusive
- audience language/questions worth researching
- one hypothesis to repeat and one to change
- safety/confusion signals
- next week's recommended experiments

Never claim causality from a small sample. Do not optimize only for reach if a post attracts the wrong audience or creates confusion.
