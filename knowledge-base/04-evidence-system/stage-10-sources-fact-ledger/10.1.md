# 10.1 — Source Register Standard and Provenance

**Status:** Proposed governance standard — owner approval pending

## Purpose
The source register records where a claim came from, what that source can establish, when it was checked, and what limitations apply. A citation is not enough if the cited source does not support the exact claim.

## Required source fields
- Source ID and short title.
- Exact URL or repository path.
- Source type (public page, owner-provided document, product demonstration, research session, official record, specialist review, or other).
- Date accessed or created, and reviewer where known.
- Exact claim(s) supported.
- What the source does not establish.
- Reliability/limitations and any conflicts.
- Whether the source contains personal or sensitive information and how it may be used.
- Next review date or freshness trigger.

## Current source records
The existing source register names S1 as the public Renomedy website, S2 as the owner-provided Renomedy Context file, and S3 as project conversation history. S1 is useful for recorded public wording; S2 for internal vision; S3 for plans and hypotheses. The register explicitly warns that internal context is not independent proof of implementation.

## Source handling rules
- Preserve original evidence and date; update records rather than rewriting history.
- Prefer direct sources over summaries when checking a claim.
- Use public sources only within their scope: a website proves what it says, not necessarily that a capability works.
- Keep access permissions and sensitive data in mind; do not paste private health data into broad marketing records.
- Record unavailable sources as unavailable; do not infer their contents.
- Do not fabricate a citation, URL, research participant, test result, or approval.

## Source precedence
Follow the existing source register's precedence: current canonical public source for public offering/status; internal owner context for intended vision; prior conversations for plans and hypotheses. Current direct product evidence is needed to establish behaviour. Conflicts should be documented and escalated.
