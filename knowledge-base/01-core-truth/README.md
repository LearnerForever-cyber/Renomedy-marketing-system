- Publication means ready for owner review, not owner-approved or validated.

## Mandatory numbering convention

File prefixes must match this stage number: Stage 1 uses `1.1.md`, `1.2.md`, etc. Stage 2 uses `2.1.md`, `2.2.md`, etc. Continue the same rule through Stage 12 (for example, Stage 10 uses `10.1.md`, `10.2.md`). Do not restart numbering at `1.x` in another stage. All files stay inside this stage's folder.
