# 5.1 — Color Tokens and Evidence Status

**Status:** Candidate direction only — owner approval pending

## Evidence status
The current fact ledger explicitly marks approved brand hex colors as unconfirmed. Prior project discussions record a cream/sage direction and candidate values such as cream #FFFBEA, sage #A7C3A0, charcoal #202522, deeper sage #8EAD8D, olive #7D9270, and amber #D99A52. These are context-derived candidates, not verified canonical tokens. Do not use them as approved design-system values until checked against the current landing page and confirmed by the owner.

## Token register format
For every token record: token name, exact value, intended role, source file or design link, date checked, status (observed / proposed / approved / superseded), approving person, allowed combinations, and contrast test results.

## Usage principles pending validation
- Define semantic roles such as page background, primary text, secondary text, interactive control, border, and status colors rather than applying colors arbitrarily.
- Never use color alone to convey meaning.
- Test text contrast against each actual background before approval.
- Check focus indicators, disabled states, errors, warnings, and links separately.
- Do not assume a palette is accessible merely because it looks soft or cohesive.

## Current unknowns
Actual values in the deployed landing page, token names in source files, contrast compliance, dark-mode behavior, and approved semantic usage remain unverified in the reviewed sources.
