# 4.2 — Logo, Mascot and Asset Governance

**Status:** Working draft — owner approval pending

## Asset truth
The reviewed source register does not identify exact approved logo files, mascot artwork, export formats, or usage rules. Therefore, this document does not certify any visual asset as final. The project has prior owner-context indicating that an existing logo/mascot direction should be preserved rather than reopened by default; the canonical source files still need to be identified and linked.

## Asset register required
For each canonical asset, record:
- asset name and purpose;
- exact repository path or approved source URL;
- file format and dimensions where relevant;
- version or revision date;
- owner/approver and approval date;
- allowed placements and minimum-size/clear-space rules, if defined;
- prohibited alterations and background constraints;
- accessibility/contrast notes where applicable.

## Mascot governance
Do not infer a mascot's name, personality, meaning, color palette, or permitted expressions from an informal description. Record the approved artwork and rules first. Do not create a new mascot or rename an established one without an explicit owner decision.

## Legal distinction
Using a logo in project materials is not proof of trademark registration, copyright ownership, or freedom to operate. Record any legal review separately; do not imply it has happened.

## Review checklist
- [ ] Canonical wordmark identified.
- [ ] Canonical mascot art and name identified, or explicitly marked undecided.
- [ ] Editable/source files and export variants located.
- [ ] Clear-space, sizing, contrast, and misuse rules approved.
- [ ] Any legal clearance claims supported by actual documentation.
