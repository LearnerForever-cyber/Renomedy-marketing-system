# Block 2 — Brand System

**Purpose:** Preserve consistent identity, visual rules, and messaging without elevating unapproved assets or preferences into canonical brand standards.

## Stages
- [Stage 4 — Identity System](stage-04-identity-system/README.md) — working draft; owner approval pending.
- [Stage 5 — Visual Design System](stage-05-visual-design-system/README.md) — working draft; owner approval pending.
- [Stage 6 — Messaging & Brand Voice](stage-06-messaging-brand-voice/README.md) — working draft; owner approval pending.

## Rules
- Public source evidence supports the brand name and recorded headline; it does not establish every logo, color, font, mascot, or layout rule.
- Preserve finalized assets when the owner identifies the exact source files; do not redesign them by default.
- Keep preferences, proposals, and approved rules distinct.
- Stage-specific files use the stage number prefix (4.x, 5.x, 6.x) and stay in the stage folder.
